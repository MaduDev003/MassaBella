# 🍕 Massa Bella - Pizzaria Web

Aplicação web de uma pizzaria que simula a experiência de pedidos online, permitindo ao usuário escolher pizzas, gerenciar o carrinho e visualizar o resumo da compra em tempo real.

**🔗 [Acesse a aplicação online](https://massa-bella.vercel.app/)**

## Funcionalidades

* Adição e remoção de pizzas no carrinho
* Controle de quantidade por item
* Cálculo automático de subtotal, desconto e total
* Geração de resumo do pedido para cópia ou envio
* Alternância de tema (claro/escuro)
* Interface com responsividade para diferentes dispositivos

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## Bibliotecas

* SweetAlert (para alertas e interações visuais)

## Objetivo do projeto

Este projeto foi desenvolvido com foco em:

* Manipulação de DOM
* Organização de código
* Simulação de regras de negócio (carrinho, desconto, total)
* Construção de interfaces interativas
* Aplicação de responsividade e experiência do usuário
